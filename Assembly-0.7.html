Assembly 0.7

Assembly now uses projects. The first time you open this version, it asks to move your deep scan into a project. Nothing is scanned again, and your sound rolls aren't touched.

Why it has to move:

  • Each show remembers its own. A project holds a show's deep scan, track names, colors and options in one file. Changing shows no longer means swapping the database and setting everything again.
  • Open it like any other file. Double-click a project, or use File ▸ Open Project… or Open Recent.
  • Several at once. Each project has its own window. They take turns with Pro Tools, and say so when one has to wait.

Before you update:

  • You can keep the old database as a backup. It's ticked whenever the drive has room. On an exFAT drive it uses as much space as the deep scan, and copying a large one takes a while.
  • Older versions of Assembly can't open projects, so it's best if everyone on a show moves together.
  • Connect the drive with your deep scan first. If it isn't connected, Assembly says so and asks again once it's back.

Also new:

  • Options save themselves. There's no Save: any option or color you change is in the project straight away, and a new project starts from the options you used last.
  • The wrong project is caught. If a session was last used in another project, Assembly says so before Match or Align.
  • A project links to its script and never holds a copy, so passing a project on doesn't pass the script with it.
  • Scan Sound Rolls is now ⇧⌘O. ⌘O is Open Project. Open Database and Choose New Database Location have gone: a deep scan lives in its project.
  • A new project goes in its rolls folder unless you choose somewhere else, so it travels with the rolls.
  • The probes in the Diagnostics menu are out of the way. Open the menu and hold Option to see them.

Help has a new page, Moving to Projects, with all of this in more detail.
